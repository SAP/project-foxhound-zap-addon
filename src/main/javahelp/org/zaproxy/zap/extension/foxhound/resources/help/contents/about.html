About Foxhound

About This Add-on

The Foxhound add-on integrates Project Foxhound, a modified Firefox browser with built-in taint tracking capabilities, into the OWASP ZAP security testing tool. This integration enables precision detection of client-side injection vulnerabilities such as DOM XSS, Stored XSS, and CSRF during dynamic security testing.

The add-on provides:

  • Real-time taint flow tracking from browser to ZAP
  • Automatic vulnerability detection and alerting
  • Interactive visualization of data flow paths
  • Persistent storage across testing sessions
  • Configurable sources and sinks for focused testing

Version 0.1.0 (2025-12-08)

Initial release with the following features:

Core Functionality:

  • Taint flow tracking integration with Project Foxhound browser
  • HTTP export server for receiving taint data (default port 55676)
  • Real-time taint flow analysis and storage
  • Event-driven architecture with FoxhoundEventPublisher

Storage:

  • Two-tier storage architecture (LRU cache + HSQLDB)
  • In-memory LRU cache (default 1000 entries, configurable 1-100,000)
  • Persistent database with normalized schema (4 tables)
  • Write-through cache strategy with lazy loading
  • Graceful degradation if database unavailable

Vulnerability Detection:

  • DOM XSS detection (Plugin ID: 40100, Risk: HIGH)
  • Stored XSS detection (Plugin ID: 40101, Risk: HIGH)
  • CSRF detection (Plugin ID: 40102, Risk: MEDIUM)
  • General taint info alerts (Plugin ID: 40103, Risk: INFO)
  • Automatic alert generation based on source+sink patterns

User Interface:

  • Foxhound panel with tree table display
  • Hierarchical view (TaintInfo → TaintRange → TaintOperation)
  • Filter dialog for sources and sinks
  • Launch Foxhound button
  • Clear All button
  • Real-time footer counter

Configuration:

  • Options panel for server port configuration
  • Configurable taint cache size
  • Sources and sinks enable/disable
  • Selenium profile management (foxhound-profile)
  • Automatic profile updates on option changes

Integration:

  • Selenium add-on integration for browser launching
  • Automatic profile creation with taint tracking preferences
  • Proxy configuration for traffic routing through ZAP
  • Sources/sinks configuration from sourcessinks.json

Internationalization:

  • Support for 48 languages via Messages.properties files
  • UI strings localized for global audience
