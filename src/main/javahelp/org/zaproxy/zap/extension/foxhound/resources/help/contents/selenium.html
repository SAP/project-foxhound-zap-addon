Selenium Integration

Foxhound integrates with ZAP's Selenium add-on to launch and manage browser instances with taint tracking enabled.

Overview

Foxhound leverages ZAP's Selenium infrastructure:

  • Selenium add-on manages browser drivers (geckodriver for Firefox)
  • Foxhound creates a specialized Firefox profile for taint tracking
  • The profile contains preferences that enable and configure taint tracking
  • Browsers launch through Selenium with the Foxhound profile
  • All browser traffic routes through ZAP's proxy automatically

Foxhound Profile

Profile Name

foxhound-profile - A dedicated Firefox profile for taint tracking

Profile Location

The profile is created in ZAP's home directory under the firefox subdirectory:

  • Windows: %USERPROFILE%\.ZAP\firefox\foxhound-profile\
  • Linux: ~/.ZAP/firefox/foxhound-profile/
  • Mac: ~/Library/Application Support/ZAP/firefox/foxhound-profile/

Profile Creation

The profile is created automatically:

  1. First time you click "Launch Foxhound" button
  2. If the profile directory doesn't exist, ZAP creates it
  3. ZAP writes taint tracking preferences to user.js
  4. Browser launches with the new profile

Profile Updates

The profile is updated whenever:

  • Export server port changes in Options
  • Sources/sinks configuration changes in Options
  • You relaunch Foxhound browser
  • ZAP rewrites user.js with current settings

Profile Configuration (user.js)

What is user.js?

user.js is a Firefox preferences file that sets configuration on browser startup. Foxhound uses it to configure taint tracking preferences.

Key Preferences

Foxhound writes these preferences to user.js:

Export URL

user_pref("taintfox.export.url", "http://localhost:55676");

Tells Foxhound where to send taint flow data. The port matches the Export Server Port in Options.

Export Enabled

user_pref("taintfox.export.enabled", true);

Enables automatic export of taint flows to ZAP.

Enabled Sources

user_pref("taintfox.sources.enabled", "location.hash,location.search,...");

Comma-separated list of sources to track. Matches the sources enabled in Options.

Enabled Sinks

user_pref("taintfox.sinks.enabled", "eval,innerHTML,document.write,...");

Comma-separated list of sinks to monitor. Matches the sinks enabled in Options.

Other Preferences

  • Taint tracking enable/disable flags
  • Logging levels
  • Performance tuning options
  • Debug settings (if enabled)

Viewing user.js

To see the generated preferences:

  1. Navigate to the profile directory (see locations above)
  2. Open user.js in a text editor
  3. Review the taintfox.* preferences

Note: Do not manually edit user.js - ZAP overwrites it on every browser launch.

Launch Process

Step-by-Step Launch

When you click "Launch Foxhound" button:

  1. Profile Check: ZAP checks if foxhound-profile exists
  2. Profile Creation/Update: Creates or updates the profile directory
  3. Write Preferences: Writes user.js with current options
  4. Selenium Request: Requests Selenium add-on to launch Firefox
  5. Binary Check: Selenium verifies Foxhound binary path is set
  6. Driver Check: Selenium ensures geckodriver is available
  7. Browser Launch: Selenium starts Foxhound with:
    • -profile flag pointing to foxhound-profile
    • Proxy settings to route traffic through ZAP
    • Additional Firefox arguments if configured
  8. Profile Load: Foxhound reads user.js and applies preferences
  9. Export Connection: Foxhound connects to export server
  10. Ready: Browser is ready, taint tracking active

Launch Errors

Common launch failure points:

  • Binary not set: "ZAP is not configured to use Foxhound!" error
  • Geckodriver missing: Selenium can't start browser
  • Port unavailable: Export server not running or port blocked
  • Profile corruption: Delete profile directory and retry

See Troubleshooting for solutions.

Browser Requirements

Binary Path Configuration

Foxhound requires the binary path to be set in Selenium options:

  1. Go to Tools → Options → Selenium → Firefox
  2. Set Binary field to Foxhound executable path
  3. Path must be absolute (e.g., C:\Foxhound\foxhound.exe)
  4. Binary must be executable and valid

Verification:

  • Path should point to foxhound.exe (Windows) or foxhound (Linux/Mac)
  • NOT regular firefox.exe
  • File must exist and have execute permissions

Geckodriver

Selenium requires geckodriver to control Firefox/Foxhound:

  • Usually bundled with Selenium add-on (auto-detected)
  • Can be manually configured in Selenium options
  • Must be compatible with Foxhound version
  • Most Foxhound versions use recent geckodriver

To set geckodriver path:

  1. Tools → Options → Selenium → Firefox
  2. Set Driver field if needed
  3. Or click Bundled button to use ZAP's bundled driver

Proxy Configuration

Selenium automatically configures the browser proxy:

  • HTTP proxy: ZAP's proxy address (usually localhost:8080)
  • HTTPS proxy: Same as HTTP proxy
  • No proxy for: localhost, 127.0.0.1 (export server)
  • Ensures all traffic routes through ZAP for analysis

No manual proxy configuration needed.

Manual Browser Launch (Alternative)

You can launch Foxhound outside ZAP for advanced scenarios:

Steps

  1. Create a Firefox profile manually
  2. Add taint tracking preferences to user.js
  3. Configure export URL: user_pref("taintfox.export.url", "http://localhost:55676");
  4. Configure proxy settings (to ZAP's proxy)
  5. Launch Foxhound with -profile flag: 
    ./foxhound -profile /path/to/profile

When to Use

  • Advanced debugging scenarios
  • Custom profile configurations
  • Automated testing scripts
  • Non-standard Selenium setups

Limitations

  • No automatic profile updates when options change
  • Must manually configure proxy
  • Must manually set preferences
  • No integration with ZAP's browser launch button

Recommendation: Use the Launch button for normal testing. Manual launch only for advanced use cases.

Multiple Browser Instances

You can launch multiple Foxhound instances:

  • Click "Launch Foxhound" button multiple times
  • Each instance uses the same foxhound-profile
  • All instances send data to the same export server
  • Taint flows from all instances appear in the same panel
  • No differentiation between instances (by design)

Use Cases:

  • Testing multiple user sessions simultaneously
  • Comparing different attack vectors in parallel
  • Distributed testing across multiple applications

Profile Management

Resetting Profile

If the profile becomes corrupted:

  1. Close all Foxhound browser instances
  2. Close ZAP (optional, but recommended)
  3. Delete the foxhound-profile directory
  4. Restart ZAP
  5. Click "Launch Foxhound" - profile will be recreated

Profile Persistence

  • Profile persists across ZAP sessions
  • Cookies, history, cache are stored in the profile
  • May grow large over time
  • Periodically delete and recreate if needed

Custom Profiles (Advanced)

For custom profile setups:

  • Create a different profile directory
  • Configure it manually
  • Use manual browser launch (see above)
  • Not recommended for most users

Troubleshooting Selenium Issues

"ZAP is not configured to use Foxhound!"

  • Binary path not set in Selenium options
  • See Getting Started for configuration

Browser Window Opens and Immediately Closes

  • Geckodriver compatibility issue
  • Profile corruption
  • Binary path incorrect
  • Check ZAP logs for Selenium errors

No Taint Flows After Launch

  • Verify export server is running (check ZAP logs)
  • Check user.js has correct export URL
  • Ensure port 55676 (or configured port) is not blocked
  • See Troubleshooting for detailed steps
