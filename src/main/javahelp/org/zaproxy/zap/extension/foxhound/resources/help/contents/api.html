API

Note: ZAP API support for the Foxhound add-on is currently under development. This page serves as a placeholder for future API documentation.

Overview

In future releases, the Foxhound add-on will provide a ZAP API for programmatic access to taint flow data and configuration.

The API will allow you to:

  • Query taint flows programmatically
  • Configure sources and sinks
  • Control the export server
  • Clear taint flow data
  • Access taint flow statistics
  • Integrate Foxhound with automated testing pipelines

Planned API Endpoints

The following API endpoints are planned for future implementation:

Views (Read-Only)

EndpointDescription
/foxhound/view/taintFlows/List all taint flows
/foxhound/view/taintFlow/Get details of a specific taint flow by ID
/foxhound/view/flowCount/Get total number of taint flows
/foxhound/view/sources/List all available sources
/foxhound/view/sinks/List all available sinks
/foxhound/view/options/Get current Foxhound options
/foxhound/view/serverPort/Get export server port
/foxhound/view/cacheSize/Get configured cache size

Actions (Modify State)

EndpointDescription
/foxhound/action/clearAll/Clear all taint flows from cache
/foxhound/action/setServerPort/Set export server port
/foxhound/action/setCacheSize/Set taint cache size
/foxhound/action/enableSource/Enable a specific source
/foxhound/action/disableSource/Disable a specific source
/foxhound/action/enableSink/Enable a specific sink
/foxhound/action/disableSink/Disable a specific sink

API Access Methods

Once implemented, the Foxhound API will be accessible via:

  • REST API: HTTP requests to ZAP's API endpoint
  • Python Client: Using the ZAP Python API client
  • Java Client: Using the ZAP Java API client
  • Other Clients: JavaScript, Ruby, PHP, etc.

Example Usage (Future)

Example API usage once implemented:

REST API

# Get all taint flows
GET http://localhost:8080/JSON/foxhound/view/taintFlows/

# Get specific taint flow
GET http://localhost:8080/JSON/foxhound/view/taintFlow/?id=123

# Clear all flows
GET http://localhost:8080/JSON/foxhound/action/clearAll/

# Set server port
GET http://localhost:8080/JSON/foxhound/action/setServerPort/?port=55677

Python Client

from zapv2 import ZAPv2

zap = ZAPv2()

# Get all taint flows
flows = zap.foxhound.taint_flows()

# Get specific flow
flow = zap.foxhound.taint_flow(id='123')

# Clear all flows
zap.foxhound.clear_all()

# Configure options
zap.foxhound.set_server_port(55677)
zap.foxhound.set_cache_size(5000)

Java Client

ClientApi api = new ClientApi("localhost", 8080);

// Get all taint flows
ApiResponse flows = api.foxhound.taintFlows();

// Clear all flows
api.foxhound.clearAll();

// Configure options
api.foxhound.setServerPort("55677");
api.foxhound.setCacheSize("5000");

Programmatic Access (Current)

Until the ZAP API is implemented, you can access Foxhound functionality programmatically within ZAP extensions:

Accessing TaintInfoStore

// Get TaintInfoStore instance
ExtensionFoxhound extension =
    Control.getSingleton().getExtensionLoader()
        .getExtension(ExtensionFoxhound.class);
TaintInfoStore store = extension.getTaintInfoStore();

// Query taint flows
TaintInfo flow = store.get(id);
Collection<TaintInfo> allFlows = store.values();

// Add listeners
extension.getEventPublisher().addEventListener(myListener);

Accessing Configuration

// Get FoxhoundOptions
FoxhoundOptions options = extension.getFoxhoundOptions();

// Read settings
int port = options.getExportServerPort();
int cacheSize = options.getTaintCacheSize();

// Modify settings (persists to ZAP config)
options.setExportServerPort(55677);
options.setTaintCacheSize(5000);

Future Enhancements

Potential future API features:

  • Filtering: Query taint flows by source, sink, URL, time range
  • Export: Export taint flows to JSON, CSV, or XML
  • Import: Import previously exported taint flows
  • Statistics: Aggregate statistics on flow types, volumes, trends
  • Webhooks: Real-time notifications when flows detected
  • Batch Operations: Bulk enable/disable sources and sinks
