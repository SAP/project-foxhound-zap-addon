Getting Started

This guide will help you install and configure the Foxhound add-on for your first taint flow analysis.

Prerequisites

Before you begin, ensure you have:

  • ZAP version 2.17.0 or later installed
  • Selenium add-on (version 15.44.0+) - install from ZAP Marketplace if needed
  • Network add-on (version 0.1.0+) - install from ZAP Marketplace if needed

Installing Foxhound Browser

Foxhound is a modified Firefox browser with built-in taint tracking capabilities. To install:

  1. Visit foxhound.ias.tu-bs.de
  2. Download the Foxhound browser for your operating system (Windows, Linux, or macOS)
  3. Extract the downloaded archive to a location on your system
  4. Note the path to the Foxhound executable (e.g., foxhound.exe on Windows or foxhound on Linux)

Configuring ZAP

Configure ZAP to use the Foxhound browser:

  1. Open ZAP
  2. Navigate to Tools → Options → Selenium → Firefox
  3. In the Binary field, enter the full path to your Foxhound executable
  4. Click OK to save your settings

Note: If the binary path is not set correctly, you will see an error message when trying to launch Foxhound.

First Launch

Launch your first Foxhound browser instance:

  1. In ZAP, locate the Foxhound panel at the bottom of the window (in the Status panels area)
  2. Click the Launch Foxhound button in the Foxhound panel toolbar
  3. A new Foxhound browser window will open
  4. The first launch may take a few moments as ZAP creates the "foxhound-profile" with taint tracking preferences

What happens during launch:

  • ZAP creates a Firefox profile named "foxhound-profile" if it doesn't exist
  • Taint tracking preferences are written to the profile's user.js file
  • The export server URL is configured to send data to ZAP (default: http://localhost:55676)
  • ZAP configures the browser proxy settings to route traffic through ZAP

Capturing Your First Taint Flow

Test the integration with a vulnerable demo application:

  1. With Foxhound browser open, navigate to https://foxhound.ias.tu-bs.de/bheu25/demo/
  2. Interact with the page (click buttons, fill forms, etc.)
  3. As you interact, Foxhound tracks data flows and sends them to ZAP
  4. Switch to the Foxhound panel in ZAP to view captured taint flows
  5. Taint flows appear in a tree table showing ID, Timestamp, URL, Sink, Source, and other details
  6. Expand taint flow nodes to see detailed operation chains

What you should see:

  • The Foxhound panel footer shows "Foxhound Taint Flows: N" where N is the count
  • Each taint flow appears as a row in the tree table
  • Rows can be expanded to show TaintRanges and individual TaintOperations
  • Alerts may be automatically raised for detected vulnerabilities (check the Alerts tab)

Understanding the Panel Display

The Foxhound panel displays taint flows in a hierarchical structure:

  • TaintInfo - Top level: represents a complete flow from source to sink
  • TaintRange - Child level: represents a specific substring of tainted data
  • TaintOperation - Leaf level: individual operations in the data flow

Key columns:

  • ID - Unique identifier for the taint flow
  • Timestamp - When the flow was captured
  • URL - Page where the flow occurred
  • Sink - Dangerous operation (e.g., eval, innerHTML)
  • Source - Data origin (e.g., location.hash, document.cookie)
  • String - The actual tainted data
  • Flow - Type of operation (e.g., string_concat, assign)
  • Location/Line - Code position where operation occurred

Next Steps

Now that you've captured your first taint flows:

  • Explore the Foxhound Panel features (filtering, clearing, etc.)
  • Understand Core Concepts of taint tracking
  • Review Alerts generated for vulnerabilities
  • Configure Options to customize behavior
  • Refer to Troubleshooting if you encounter issues
