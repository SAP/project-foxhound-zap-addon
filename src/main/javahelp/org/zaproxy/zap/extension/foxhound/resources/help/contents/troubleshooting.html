Troubleshooting

This guide covers common issues and their solutions when using the Foxhound add-on.

Common Issues

1. "ZAP is not configured to use Foxhound!"

Symptom: Error dialog appears when clicking the Launch Foxhound button.

Cause: The Firefox binary path in Selenium options is not set or does not point to the Foxhound executable.

Solution:

  1. Download and install Foxhound from foxhound.ias.tu-bs.de
  2. In ZAP, go to Tools → Options → Selenium → Firefox
  3. Set the Binary field to the full path of your Foxhound executable
  4. Click OK to save
  5. Try launching again

Verification: The binary path should point to a file that exists and is executable.

2. No Taint Flows Appearing

Symptom: Foxhound browser launches successfully, but no taint flows appear in the panel.

Possible Causes and Solutions:

Export Server Not Running

  • Check ZAP logs for "FoxhoundExportServer started on port 55676" message
  • If missing, restart ZAP
  • If port is in use, change the port in Options (see issue #3 below)

Port Blocked or Incorrect

  • Verify that port 55676 (or your configured port) is not blocked by firewall
  • Check that the export URL in foxhound-profile/user.js matches the server port
  • Profile location: typically in ZAP's home directory under firefox/foxhound-profile/

Sources/Sinks Disabled

  • Go to Tools → Options → Foxhound
  • Ensure at least some sources and sinks are enabled
  • Try enabling all sources and sinks temporarily
  • Relaunch Foxhound browser

Foxhound Not Instrumented

  • Verify you downloaded the Foxhound browser, not regular Firefox
  • Check browser console (F12) for taint tracking messages
  • Foxhound should display instrumentation information in the console

No Taint Flows in Application

  • The web application you're testing might not have detectable data flows
  • Test with the demo site: https://foxhound.ias.tu-bs.de/bheu25/demo/
  • Ensure you're interacting with the page (clicking, typing) to trigger flows

3. Port Already in Use

Symptom: ZAP logs show "Failed to start FoxhoundExportServer" or "Address already in use" error.

Cause: Another application is using port 55676, or a previous ZAP instance didn't release the port.

Solution:

  1. Close all ZAP instances
  2. Check for processes using port 55676:
    • Windows: netstat -ano | findstr :55676
    • Linux/Mac: lsof -i :55676
  3. Kill the process or wait for it to release the port
  4. Alternatively, change the port in ZAP:
    • Go to Tools → Options → Foxhound
    • Set Export Server Port to a different port (e.g., 55677)
    • Click OK
    • Restart ZAP for the change to take effect
  5. Relaunch Foxhound browser

Note: After changing the port, you must relaunch the Foxhound browser for the new profile settings to be written.

4. Browser Launch Fails

Symptom: Error when clicking Launch button, or browser window briefly appears and closes.

Possible Causes and Solutions:

Geckodriver Issues

  • Ensure geckodriver is installed and accessible
  • Check Selenium add-on configuration for geckodriver path
  • Try using the bundled geckodriver (Selenium Options → Firefox → Bundled button)

Profile Corruption

  • Delete the foxhound-profile directory (ZAP will recreate it)
  • Profile location varies by platform:
    • Windows: %USERPROFILE%\.ZAP\firefox\foxhound-profile\
    • Linux: ~/.ZAP/firefox/foxhound-profile/
    • Mac: ~/Library/Application Support/ZAP/firefox/foxhound-profile/
  • Relaunch Foxhound browser

Binary Path Issues

  • Verify the binary path has no typos
  • Ensure path uses correct separators for your OS
  • Try putting the path in quotes if it contains spaces
  • Check file permissions (must be executable)

5. Performance Issues

Symptom: ZAP becomes slow or unresponsive with many taint flows.

Cause: Large number of taint flows exceeds cache capacity or causes UI rendering delays.

Solutions:

Increase Cache Size

  1. Go to Tools → Options → Foxhound
  2. Increase Taint Cache Size (default 1000, max 100,000)
  3. Larger cache reduces database queries but uses more memory
  4. Recommended: Start with 5000 for high-traffic testing

Use Filtering

  • Click Show Filter in the Foxhound panel
  • Disable noisy sources or sinks you don't need
  • Reduces both collection and display overhead

Clear Old Flows

  • Click Clear All to remove flows from cache and display
  • Note: Flows remain in database and reload on restart
  • To permanently delete, manually clear the database (advanced)

Limit Testing Scope

  • Test smaller portions of the application at a time
  • Clear flows between testing sessions
  • Use targeted testing rather than broad crawling

6. Database Errors

Symptom: Errors in logs related to TaintInfoTable or database operations.

Cause: Database corruption, permissions issues, or disk space problems.

Solutions:

  • Check available disk space
  • Close ZAP and delete the database file (ZAP will recreate it):
    • Database location: ZAP home directory, typically db/ folder
    • Look for zapdb or zapdb.h2.db files
  • If issues persist, check ZAP logs for specific error messages
  • Note: The add-on gracefully degrades to memory-only mode if database is unavailable

Graceful Degradation: If database operations fail, Foxhound continues working with in-memory cache only. Flows will not persist across ZAP restarts, but real-time tracking still works.

7. Missing Alerts

Symptom: Taint flows visible in panel, but no alerts raised.

Possible Causes and Solutions:

Alert Thresholds

  • Check that passive scanning is enabled in ZAP
  • Verify alert threshold settings (default should catch high-risk flows)

Source/Sink Mismatch

  • Alerts only raised for specific source+sink combinations
  • Review Alerts documentation for required combinations
  • Example: DOM XSS requires URL/INPUT sources + XSS sinks
  • If flows don't match patterns, only "General Taint Info" alerts are raised

EventBus Issues

  • Restart ZAP to reset event system
  • Check logs for EventBus errors

8. UI Issues

Symptom: Foxhound panel not visible, tree table not updating, or filter dialog problems.

Solutions:

  • Check that the Foxhound panel tab is visible at the bottom of ZAP
  • Try resizing or undocking the panel
  • Restart ZAP if UI elements are unresponsive
  • Check for conflicts with other add-ons (disable temporarily to test)
  • Verify ZAP version compatibility (2.17.0+ required)

Getting Help

Logging

Enable detailed logging to diagnose issues:

  1. In ZAP, go to Tools → Options → JVM
  2. Increase log level for debugging (e.g., DEBUG or TRACE)
  3. Restart ZAP
  4. Check log files in ZAP home directory under logs/
  5. Look for messages containing "Foxhound", "TaintInfo", or "FoxhoundExportServer"

Reporting Issues

If problems persist, report them on GitHub:

  • Visit GitHub Issues
  • Search for existing issues first
  • When creating a new issue, include:
    • ZAP version
    • Foxhound add-on version
    • Foxhound browser version
    • Operating system
    • Steps to reproduce
    • Relevant log excerpts
    • Screenshots if applicable

Known Limitations

  • Alpha Status: This add-on is in alpha. Expect bugs and breaking changes.
  • Browser Compatibility: Only works with Foxhound browser, not regular Firefox.
  • Performance: Very large numbers of flows (50,000+) may impact performance.
  • Platform Support: Tested on Windows, Linux, and macOS. Other platforms may have issues.
