Foxhound

The Foxhound add-on integrates Project Foxhound, a modified Firefox browser that tracks client-side data flows, with ZAP for precision detection of client-side injection vulnerabilities during dynamic testing.

What is Foxhound?

Foxhound is a modified Firefox browser that instruments JavaScript execution to track how data flows through web applications. It identifies:

  • Sources - Where potentially dangerous data originates (URL parameters, cookies, localStorage, etc.)
  • Sinks - Where data is used in potentially dangerous ways (eval, innerHTML, document.write, etc.)
  • Taint Flows - The complete path data takes from source to sink

Key Features

  • Real-time taint flow tracking during browser execution
  • Persistent storage of taint flows across ZAP sessions
  • Automatic vulnerability detection for DOM XSS, Stored XSS, and CSRF
  • Interactive UI panel for exploring data flows
  • Configurable sources and sinks
  • LRU cache with database persistence (default 1000 entries)
  • Seamless Selenium integration for automated testing

How It Works

  1. Launch a Foxhound browser from ZAP using the toolbar button
  2. Navigate to target web applications
  3. Foxhound tracks client-side data flows in real-time
  4. Taint flow data is sent to ZAP's export server (default port 55676)
  5. ZAP analyzes flows and raises alerts for vulnerabilities
  6. View and filter taint flows in the Foxhound panel

Requirements

  • Foxhound browser binary (download from foxhound.ias.tu-bs.de)
  • ZAP 2.17.0 or later
  • Selenium add-on (version 15.44.0+)
  • Network add-on (version 0.1.0+)
