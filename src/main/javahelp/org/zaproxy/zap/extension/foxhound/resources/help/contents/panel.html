Foxhound Panel

The Foxhound panel is the main interface for viewing and managing taint flows captured during browser sessions.

Panel Location

The Foxhound panel is located in the Status panels area at the bottom of the ZAP window, alongside other panels like History and Search. Click the Foxhound tab to bring it into focus.

Toolbar Buttons

The panel toolbar provides quick access to key functions:

Launch Foxhound

The Launch Foxhound button opens a new Foxhound browser instance with taint tracking enabled. The browser is automatically configured to:

  • Use the foxhound-profile Firefox profile
  • Send taint flow data to ZAP's export server
  • Route traffic through ZAP's proxy
  • Track enabled sources and sinks

Show Filter

The Show Filter button opens the filter dialog, allowing you to control which taint flows are displayed. See the Filtering section below for details.

Clear All

The Clear All button removes all taint flows from the panel display and clears the in-memory cache. Note that this does not delete flows from the database - they will be reloaded when ZAP restarts.

Tree Table Display

Taint flows are displayed in a hierarchical tree table with three levels:

Level 1: TaintInfo (Parent)

The top level represents a complete taint flow from source to sink. Each TaintInfo row includes:

  • ID - Unique identifier (e.g., 1, 2, 3...)
  • Timestamp - When the flow was captured (e.g., "2025-03-04 14:23:45")
  • URL - The page where the flow occurred
  • Sink - The dangerous operation (e.g., "eval", "innerHTML", "document.write")
  • Source - The data origin (e.g., "location.hash", "document.cookie")
  • String - The complete tainted string flowing into the sink

Level 2: TaintRange (Child)

Expand a TaintInfo row to see TaintRange entries. Each TaintRange represents a specific substring of the tainted data and shows:

  • String - The substring that is tainted
  • From/To - The character positions in the parent string (e.g., "0-15")
  • Other columns show aggregate information from the operation chain

Level 3: TaintOperation (Leaf)

Expand a TaintRange to see individual TaintOperations in the data flow chain. Each operation shows:

  • Flow - The operation type (e.g., "string_concat", "assign", "charCodeAt")
  • Function - The JavaScript function where the operation occurred
  • Location - The file path or URL of the source code
  • Line - The line number in the source file
  • Script Line - The line number in the script (if different from location line)

Example hierarchy: 

TaintInfo #1: eval() called with data from location.hash
  ├─ TaintRange: "alert('xss')" (positions 0-13)
  │  ├─ Operation 1: string_concat at file.js:42
  │  ├─ Operation 2: assign at file.js:45
  │  └─ Operation 3: eval at file.js:50
  └─ TaintRange: "xss" (positions 7-10)
     └─ Operation 1: substring at file.js:43

Filtering Taint Flows

Use the filter dialog to control which taint flows are displayed:

  1. Click the Show Filter button in the toolbar
  2. The filter dialog displays two lists:
    • Sources - All available data sources (e.g., location.hash, document.cookie)
    • Sinks - All available dangerous operations (e.g., eval, innerHTML)
  3. Check the boxes next to sources/sinks you want to display
  4. Uncheck boxes for sources/sinks you want to hide
  5. Click OK to apply the filter
  6. The tree table immediately updates to show only matching flows

Note: Filtering only affects the panel display. All taint flows remain stored in the database and cache.

Use cases for filtering:

  • Focus on specific vulnerability types (e.g., show only eval sinks for JavaScript injection)
  • Exclude noisy sources (e.g., hide localStorage flows)
  • Investigate specific attack vectors (e.g., URL-based sources only)

Footer Counter

The panel footer displays "Foxhound Taint Flows: N" where N is the current count of visible flows. This count:

  • Updates in real-time as new flows arrive
  • Reflects the filtered view (not the total in the database)
  • Resets to 0 when Clear All is clicked
  • Restores the full count when ZAP reopens the database

Interacting with Flows

Expanding and Collapsing

  • Click the tree control icon (+ or -) to expand or collapse rows
  • Double-click a row to toggle expansion
  • Expand TaintInfo to see TaintRanges, expand TaintRanges to see TaintOperations

Sorting

  • Click column headers to sort the table
  • Click again to reverse sort order
  • Sorting applies to the current hierarchy level

Selecting Rows

  • Click a row to select it
  • Selected rows are highlighted
  • Use Shift+Click to select multiple contiguous rows
  • Use Ctrl+Click (Cmd+Click on Mac) to select multiple non-contiguous rows
