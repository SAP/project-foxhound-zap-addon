Options

The Foxhound options panel allows you to configure server settings, cache behavior, and enabled sources/sinks.

Accessing Options

To access Foxhound options:

  1. In ZAP, navigate to Tools → Options
  2. Expand the Foxhound section in the left panel
  3. Modify settings as needed
  4. Click OK to save changes

Export Server Port

The export server port is where Foxhound browsers send taint flow data to ZAP.

Default: 55676

When to Change:

  • Port 55676 is already in use by another application
  • Firewall or security policy blocks port 55676
  • Testing multiple ZAP instances simultaneously

Valid Range: 1-65535 (recommended: use ports above 1024 to avoid requiring admin privileges)

Impact of Changing:

  • The export server will restart on the new port
  • The foxhound-profile will be updated with the new port
  • You must relaunch Foxhound browser for the new settings to take effect
  • Any currently running Foxhound browsers will continue using the old port

Note: If you see "Port Already in Use" errors, refer to the Troubleshooting guide.

Taint Cache Size

The taint cache size controls how many taint flows are kept in memory for fast access.

Default: 1000 entries

Range: 1 to 100,000 entries

How It Works - LRU Cache:

  • Foxhound uses a Least Recently Used (LRU) cache strategy
  • The most recently accessed flows are kept in memory
  • When the cache exceeds the configured size, the least recently used flows are evicted
  • Evicted flows remain in the database and are loaded on-demand when accessed
  • All flows (cached or not) are persisted to the database immediately

Memory vs. Database Trade-offs:
Cache SizeMemory UsagePerformanceUse Case
Small (100-500)LowSlower for many flowsLimited memory environments
Medium (1000-5000)ModerateBalancedMost users (default)
Large (10000-50000)HighFast for high-volumeIntensive testing sessions
Very Large (50000+)Very HighFastest, may impact ZAPAdvanced users only

Tuning Guidelines:

  • Monitor memory usage: Larger cache uses more RAM (roughly 1-2 KB per taint flow)
  • If ZAP becomes sluggish with many flows, increase cache size
  • If memory is constrained, decrease cache size
  • For high-traffic testing, start with 5000 and adjust based on performance

When to Clear Cache:

  • Use Clear All button in Foxhound panel to empty cache
  • Clears in-memory cache but not the database
  • Flows reload from database on ZAP restart

Sources Configuration

The sources list controls which data origins Foxhound tracks.

Enabled Sources: Foxhound marks data from these origins as tainted

Disabled Sources: Foxhound ignores data from these origins

Impact on Tracking:

  • Enabled sources: Data flows are tracked and sent to ZAP
  • Disabled sources: Data flows are not tracked, reducing overhead
  • Changes require relaunching Foxhound browser to take effect

When to Disable Sources:

  • Reduce noise: Disable sources you're not interested in
  • Performance: Fewer sources = less tracking overhead
  • Focused testing: Enable only sources relevant to your test scenario

Common Source Categories:

  • URL Sources: location.*, document.URL, etc. (for DOM XSS testing)
  • Storage Sources: localStorage, sessionStorage, document.cookie (for stored XSS)
  • Network Sources: XMLHttpRequest, fetch responses (for response-based attacks)
  • Input Sources: Form inputs, textareas (for input validation testing)

Recommendation: Start with all sources enabled, then disable noisy ones as needed.

Sinks Configuration

The sinks list controls which dangerous operations Foxhound monitors for tainted data.

Enabled Sinks: Foxhound reports when tainted data reaches these operations

Disabled Sinks: Foxhound ignores these operations

Impact on Detection:

  • Enabled sinks: Taint flows ending at these sinks are reported
  • Disabled sinks: Taint flows ending at these sinks are NOT reported
  • Disabling sinks does not prevent tracking, only reporting
  • Changes require relaunching Foxhound browser to take effect

When to Disable Sinks:

  • Focus on specific vulnerability types (e.g., disable storage sinks if only testing XSS)
  • Reduce false positives: Disable sinks that frequently fire in the application
  • Performance: Fewer sinks = less reporting overhead

Common Sink Categories:

  • Code Execution: eval, Function, setTimeout, setInterval (highest risk)
  • DOM Manipulation: innerHTML, outerHTML, document.write
  • URL Navigation: location.href, window.open
  • Storage Operations: localStorage.setItem, document.cookie
  • Network Operations: fetch, XMLHttpRequest.open

Warning: Disabling critical sinks (eval, innerHTML) may cause you to miss important vulnerabilities.

Recommendation: Keep all sinks enabled unless you have a specific reason to disable them.

Selenium Profile Integration

Foxhound automatically manages a Firefox profile named "foxhound-profile" with taint tracking preferences.

Profile Location:

  • Windows: %USERPROFILE%\.ZAP\firefox\foxhound-profile\
  • Linux: ~/.ZAP/firefox/foxhound-profile/
  • Mac: ~/Library/Application Support/ZAP/firefox/foxhound-profile/

What Gets Written:

  • user.js - Firefox preferences file with:
    • Export URL: http://localhost:[port]
    • Enabled sources list
    • Enabled sinks list
    • Other taint tracking configuration
  • Profile is created on first launch
  • Profile is updated whenever options change

Manual Profile Management:

  • Usually not needed - ZAP manages the profile automatically
  • If profile becomes corrupted, delete the directory and ZAP will recreate it
  • You can view user.js to see the generated preferences
  • Do not manually edit user.js - ZAP overwrites it on each launch

Applying Changes

Different settings take effect at different times:
SettingWhen AppliedAction Required
Export Server Port Immediately (server restarts) Relaunch Foxhound browser
Taint Cache Size Immediately None (affects future operations)
Sources On browser launch Relaunch Foxhound browser
Sinks On browser launch Relaunch Foxhound browser

Important: Always relaunch the Foxhound browser after changing sources, sinks, or the export server port.
